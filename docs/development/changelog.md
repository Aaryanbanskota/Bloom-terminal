# Changelog

## [0.1.0-beta] - 2026-07-16
### Added
- Interactive Intro Dashboard including Weather, Song Player (folder/URL playback), System Stats (Battery + CPU), and running program listings.
- Settings Dialog with toggle switches for lock screen and active wingits.
- Secure local encryption mode using AES-256-GCM to lock SQLite data files.
- Responsive dashboard window layout changes (resizes based on size classes).
- Universal multi-distribution installer `scripts/setup.sh` (supporting apt, dnf, pacman, zypper).
- Lightweight bootstrap installer `install.sh` to download and install Bloom releases dynamically from GitHub.
